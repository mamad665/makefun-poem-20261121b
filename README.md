($35 in USDC).

## The poem

> I stopped.
> Not because the road ended —
> because my feet did.
> The world kept shouting go.
> I stayed,
> one quiet breath,
> one unhurried heart,
> and the loud world learned
> to wait for me.

## Run it

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when
`OUTPUT_DIR` is set). Deterministic, standard library only, no network.
Running it twice writes the same bytes.
